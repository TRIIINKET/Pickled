# PICKLED

PICKLED is a collaborative web development project for an indoor pickleball venue based in Makati. The website is designed to provide users with an accessible and engaging platform for exploring the venue, viewing available services, and managing court-related activities.

The project focuses on creating a modern, responsive, and user-friendly experience through front-end and back-end web development technologies.

## Features

- Homepage interface
- Court information and booking pages
- Social play page
- Private event page
- User login system
- Contact page
- Responsive website layout

## Technologies Used

- PHP
- MySQL / PDO
- HTML
- CSS
- JavaScript
- XAMPP
- Git & GitHub

## Project Status

This project is currently under development for academic and collaborative learning purposes.

## Local database setup

Import `backend/database/schema.sql` into MySQL before running the app.

Default local connection:

- DSN: `mysql:host=127.0.0.1;port=3306;dbname=pickled;charset=utf8mb4`
- User: `root`
- Password: empty

You can override those with `PICKLED_DB_DSN`, `PICKLED_DB_USER`, and `PICKLED_DB_PASS`.
