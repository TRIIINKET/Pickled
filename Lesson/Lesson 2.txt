PHP Variables

• In PHP, you identify variables with a dollar sign ($) in front of the
variable name.
• You must start a variable name with either a letter or an underscore.

ex:
$test
$Test1
$_another_test

• To assign a value to a variable:

ex:

$test = “This is a test string”;


Data Types

PHP supports the ff data types:

• Integer – store whole numbers
• Float – or double
• Boolean – stores a T or F values
• String – stores alphabets or characters
• Array – stores multiple values
• Object – store instances of classes
• Null – a special data type that means the variable doesn’t
contain a value
• Reference – stores a pointer to a complex data type
