Defining a class
• To define a class, used the class keyword, along with the class name, followed
by any statements contained in the class.
• TRY IT! Program#1 (ooptest1.php)

Defining a class (cont.)

Class - is a blueprint/template for objects (e.g. class Product)
Object - is the actual product (e.g. Carrots, Eggplants)
Public - the member can be accessed from outside the class code.
Private - the member can only be accessed from inside the class code.
Protected - the member can only be accessed from a child class.
$this - current object being used.

Defining accessor magic methods

Accessor magic methods are methods you use to access the
private property values you define in the class.
Because properties are private.
So PHP uses magic methods:

✅ __set()
✅ __get()
